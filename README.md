# Бот-подарок

## Запуск
1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Скопируй `.env.example` в `.env`, вставь токен и ID (свой и её; узнать ID можно через @userinfobot).
3. Установи и запусти:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Открой бота в Telegram, нажми `/start`.

Бот работает, пока запущен `bot.py`. Чтобы он отвечал всегда, запусти его на VPS или бесплатном хостинге (например, Railway / Render / PythonAnywhere), либо на домашнем компьютере, который включён.

## Как редактировать тексты
Всё в `messages.json`:
- `welcome` — приветствие;
- `categories` — кнопки меню. У каждой: `id` (уникальный, латиницей), `emoji`, `title`, `messages` (список фраз; одна нажатая кнопка показывает случайную, «Ещё одна» — следующую без повторов).
- Добавить событие — скопируй блок категории и поменяй поля. Удалить — убери блок.
- Все тексты с пометкой `ЗАМЕНИ:` — заготовки, замени на свои.
- После правки перезапусти бота. Если в JSON ошибка, бот при старте скажет, в какой строке.

## Сообщения по расписанию
- **Знаковые события.** У категории есть поле `date`. `"01-01"` (ММ-ДД) — приходит каждый год, `"2027-05-20"` (ГГГГ-ММ-ДД) — один раз. Сообщение (случайное из категории) приходит в 00:00 этого дня. `null` — без даты, категория только в меню. Дату дня рождения и годовщины впиши сам.
- **Случайные признания.** Блок `random`: списки `love` и `miss`, `per_day` — сколько раз в день, `from`/`to` — в какие часы. Время каждый день выбирается случайно.
- `timezone` — часовой пояс (по умолчанию `Europe/Moscow`).
- Бот пишет ей только после того, как она один раз нажала `/start`. В `.env` укажи `GIRLFRIEND_ID`, чтобы автосообщения шли только ей, а не тебе тоже.
- Бот должен быть включён в 00:00. Если он был выключен, а запущен позже в тот же день, событие придёт при запуске. Случайные сообщения, время которых прошло больше 90 минут назад, пропускаются.
- Что уже отправлено, хранится в `state.json`. Чтобы отправить событие повторно, удали его оттуда.

## Деплой в Docker
На сервере (нужны Docker и docker compose) в папке проекта:
```
cp .env.example .env      # впиши BOT_TOKEN, ID; PROXY_URL оставь пустым, если сервер за границей
docker compose up -d --build
docker compose logs -f    # смотреть логи
```
- Автозапуск при перезагрузке сервера включён (`restart: unless-stopped`).
- Изменил `messages.json` → `docker compose restart`. Менял `bot.py` → `docker compose up -d --build`.
- `state.json` лежит в папке `data/` рядом с проектом и сохраняется между перезапусками.
- Сервер лучше брать вне России, тогда Telegram доступен без прокси. Часовой пояс для событий в 00:00 задаётся в `messages.json` (`timezone`), а не на сервере.
- Не выкладывай `.env` в git: он уже в `.gitignore`.

## Ответы тебе
Под каждым автоматическим сообщением (событие в 00:00 или случайное признание) есть кнопка «ответить андрею». Она нажимает, пишет текст (можно фото, голосовое), и бот пересылает это в твой аккаунт. Для этого впиши в `.env` `OWNER_ID` (твой ID) и убедись, что ты хотя бы раз нажал `/start` у бота, иначе Telegram не даст ему написать тебе. Если `OWNER_ID` пуст, кнопки нет.

## Счётчик слёз
Кнопка «счётчик слёз» в меню: `+1` / `-1` за сегодня и графики за неделю и месяц (столбцы по дням, среднее, самый тяжёлый день). Данные хранятся в `state.json` (`tears`) отдельно по пользователям. Ни тебе, ни кому-то ещё бот их сам не отправляет.
